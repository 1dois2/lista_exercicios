Aplicativo focado na gestão de treinos
como rodar
1. abra o terminal na pasta do projeto e instale as dependências com: `npm install`
2. inicie o servidor rodando: `npx expo start`
3. escolha a opcao web digitando a tecla w
4. O que é o useEffect e qual o seu papel no ciclo de vida de um componente?**
O useEffect é uma ferramenta do React usada para executar tarefas "escondido", sem atrapalhar a tela do usuário.
Ele permite que seu código interaja com o mundo externo, como fazer requisições a APIs, manipular o DOM, definir temporizadores ou salvar dados.
